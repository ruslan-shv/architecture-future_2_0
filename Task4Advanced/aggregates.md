# Агрегаты по доменам

## Clinical Care

### Patient (корень)

| | |
|--|--|
| **Границы** | Один пациент и его идентификаторы |
| **Инварианты** | Уникальный `patientId` в домене; согласие на обработку ПДн |
| **Ключ** | `patientId` (UUID) |

### MedicalVisit (корень)

| | |
|--|--|
| **Границы** | Визит, назначения в рамках одного визита |
| **Инварианты** | Визит привязан к существующему Patient; нельзя закрыть без врача |
| **Ключ** | `visitId` |

## Retail Banking

### CreditAgreement (корень)

| | |
|--|--|
| **Границы** | Договор, график, статус |
| **Инварианты** | Сумма > 0; переход статусов: Draft → Active → Closed |
| **Ключ** | `creditId` |

### Account (корень)

| | |
|--|--|
| **Границы** | Счёт и баланс |
| **Инварианты** | Баланс не уходит ниже лимита без овердрафта |
| **Ключ** | `accountId` |

## Clinical AI

### InferenceJob (корень)

| | |
|--|--|
| **Границы** | Один запрос на анализ |
| **Инварианты** | Ссылка на `visitId`; результат версионируется |
| **Ключ** | `jobId` |

## Analytics (read models)

Денормализованная проекция из `PatientRegistered`, `VisitCompleted` - без диагнозов и снимков.
